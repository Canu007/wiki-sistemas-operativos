# Unidad 4: Interbloqueos

## Introducción

Un interbloqueo, también conocido como deadlock,
ocurre cuando dos o más procesos quedan bloqueados
porque cada uno espera recursos que están siendo
utilizados por otros procesos.

## Temas que estudiaremos

1. Concepto de interbloqueo.
2. Condiciones necesarias para un interbloqueo.
3. Condiciones de Coffman.
4. Prevención de interbloqueos.
5. Evitación de interbloqueos.
6. Algoritmo del banquero.
7. Detección y recuperación.
