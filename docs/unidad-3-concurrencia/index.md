# Unidad 3: Concurrencia y Sincronización

## Introducción

La concurrencia permite que varios procesos o hilos
realicen actividades durante períodos de tiempo
superpuestos dentro de un sistema operativo.

Esta unidad estudia los mecanismos utilizados para
coordinar la ejecución de procesos y evitar conflictos
cuando comparten recursos.

## Temas que estudiaremos

1. Introducción a la concurrencia.
2. Exclusión mutua.
3. Secciones críticas.
4. Condiciones de carrera.
5. Semáforos.
6. Monitores.
7. Sincronización de procesos.
