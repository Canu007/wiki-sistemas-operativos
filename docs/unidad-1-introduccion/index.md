# Unidad 1: Introducción a los Sistemas Operativos

## 1.1. ¿Qué es un sistema operativo?

Un sistema operativo es el software encargado de administrar los recursos de una computadora y proporcionar servicios para que los programas puedan ejecutarse.

Actúa como intermediario entre el hardware, las aplicaciones y los usuarios.

Entre sus responsabilidades principales se encuentran la administración del procesador, la memoria, los archivos y los dispositivos de entrada y salida.

## 1.2. Objetivos de un sistema operativo

Los principales objetivos de un sistema operativo son:

- **Administrar los recursos:** distribuir el uso del procesador, la memoria y los dispositivos.
- **Facilitar la ejecución de programas:** proporcionar servicios para que las aplicaciones funcionen correctamente.
- **Organizar la información:** administrar archivos y directorios.
- **Proteger el sistema:** controlar el acceso a los recursos y aislar los procesos cuando corresponde.
- **Facilitar la interacción:** ofrecer interfaces para que los usuarios puedan utilizar la computadora.

## 1.3. Funciones principales

### Administración de procesos

Controla la creación, ejecución y finalización de los procesos, así como la asignación del procesador.

### Administración de memoria

Organiza el uso de la memoria principal y asigna espacio a los procesos según las necesidades del sistema.

### Administración de archivos

Permite crear, leer, modificar y eliminar archivos y directorios.

### Administración de dispositivos

Coordina la comunicación con dispositivos como teclados, pantallas, impresoras y unidades de almacenamiento.

### Seguridad y protección

Gestiona permisos y mecanismos de protección para evitar accesos no autorizados a los recursos.

## 1.4. Ejemplos de sistemas operativos

Algunos ejemplos de sistemas operativos son:

| Sistema operativo | Características generales |
|---|---|
| GNU/Linux | Familia de sistemas tipo Unix, utilizada en computadoras personales, servidores y sistemas embebidos. |
| Microsoft Windows | Sistema operativo de escritorio ampliamente utilizado. |
| macOS | Sistema operativo de Apple para computadoras Mac. |
| Android | Sistema operativo basado en el kernel Linux, utilizado principalmente en dispositivos móviles. |
| iOS | Sistema operativo de Apple para dispositivos móviles compatibles. |

## 1.5. Importancia de los sistemas operativos

Los sistemas operativos permiten utilizar el hardware de forma organizada y ofrecen servicios comunes a las aplicaciones.

Sin ellos, los programas tendrían que encargarse directamente de muchas tareas relacionadas con los dispositivos y los recursos de la computadora.

Comprender su funcionamiento es fundamental para estudiar los procesos, la concurrencia, los interbloqueos y la administración de memoria.

## 1.6. Resumen

En esta sección aprendimos que el sistema operativo administra los recursos de una computadora, proporciona servicios a las aplicaciones y facilita la interacción entre los usuarios y el hardware.

En las siguientes secciones estudiaremos cómo han evolucionado los sistemas operativos, cómo se clasifican y cómo se comunican las aplicaciones con el núcleo del sistema.
