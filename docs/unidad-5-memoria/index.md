# Unidad 5: Administración de Memoria

## Introducción

La administración de memoria es una función
fundamental de los sistemas operativos.

Permite organizar, asignar y liberar la memoria
utilizada por los diferentes procesos.

## Temas que estudiaremos

1. Introducción a la administración de memoria.
2. Asignación de memoria.
3. Fragmentación interna y externa.
4. Paginación.
5. Segmentación.
6. Memoria virtual.
7. Reemplazo de páginas.
